02 / The rule

Missing is a data state.

A reported zero participates in the sum and counts toward coverage. A missing observation does neither. When every region is missing, the result is null.

This example flags any hour with fewer than three reporting regions as partial. Coverage is a count of regions, not a share of demand.

Runs in your browserJavaScript
const { points, coverage } =
  entsoe.sumPoints(regionSeries);

// Require all three regions in this demo.
const partial =
  entsoe.partialAbove(coverage, 1);
